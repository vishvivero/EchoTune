## NOTES FOR YOU

### Character Counts (App Store Limits):
- ✅ App Name: 30 characters max → "EchoTune" (9 chars)
- ✅ Subtitle: 30 characters max → "AI Voice to Text for Mac" (24 chars)
- ✅ Promotional Text: 170 characters max → All options under 170
- ✅ Keywords: 100 characters max → All options under 100
- ✅ Description: 4000 characters max → Version 1 is ~3,950 chars

### What to Do:
1. Copy Version 1 description (or Version 2 if you prefer shorter)
2. Paste into App Store Connect → App Information → Description
3. Choose one keyword option
4. Choose one promotional text option
5. Fill in screenshot captions when uploading images
6. Copy "What's New" text for version 1.0

### Customization Needed:
- Replace `[YOUR NAME/COMPANY NAME]` with your actual name
- Replace support@echotune.app if you use a different email
- Replace echotune.app URLs if you use a different domain

Everything else is ready to use as-is!
