Common Issues

Microphone access is denied

EchoTune needs microphone access to record your voice. To grant access:

  1. Open System Settings → Privacy & Security → Microphone
  2. Find EchoTune in the list and enable the toggle
  3. Restart EchoTune

Text isn't being inserted into my app

EchoTune uses Accessibility APIs to insert text. Make sure access is granted:

  1. Open System Settings → Privacy & Security → Accessibility
  2. Find EchoTune in the list and enable the toggle
  3. If EchoTune isn't listed, click the + button and add it manually
  4. Restart EchoTune

The keyboard shortcut doesn't work

If ⌘⇧D doesn't trigger recording:

  1. Check if another app is using the same shortcut
  2. Open EchoTune Settings → Keyboard Shortcuts and set a different shortcut
  3. Make sure EchoTune is running (check the menu bar icon)

Transcription accuracy is poor

To improve transcription quality:

  1. Use a good quality microphone and speak clearly
  2. Reduce background noise (music, TV, other people talking)
  3. Try a larger AI model (Settings → AI Models → choose Base or Medium)
  4. Enable AI Enhancement (Settings → Advanced) for grammar and filler removal

The app is slow or unresponsive

If EchoTune feels sluggish:

  1. Use the Tiny or Base model for faster processing
  2. Try cloud transcription (Groq) for lightning-fast results
  3. Close other resource-intensive apps
  4. Ensure your Mac isn't in Low Power Mode
