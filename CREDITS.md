# Credits

## Inspiration & lineage

EchoTune's dictation experience was inspired by **VoiceInk**
([github.com/Beingpax/VoiceInk](https://github.com/Beingpax/VoiceInk)), an
open-source macOS dictation app by **Prakash Joshi Pax**, licensed under
**GPL-3.0** ([tryvoiceink.com](https://tryvoiceink.com)).

Early development of EchoTune began as a learning exercise while studying
VoiceInk's approach to on-device dictation. EchoTune grew out of a desire for
a cleaner, more personal interface and a fully self-hosted audio stack that
could run without a paid cloud subscription. EchoTune is an **independent
implementation**: its dictation-related source is written from behavior
specifications, with no code reuse from VoiceInk. In the spirit of that
lineage, EchoTune is likewise released under GPL-3.0.

The author is grateful to VoiceInk and BeingPax for proving that a focused,
privacy-first dictation tool could be built by an individual, and for setting
the benchmark that EchoTune aims to honor.
