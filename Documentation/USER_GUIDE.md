## 🚀 Getting Started

### Installation

**From App Store:**
1. Search for "EchoTune" in Mac App Store
2. Click "Get" or "Download"
3. Open EchoTune from Applications folder

**From Website:**
1. Download EchoTune.dmg from echotune.app
2. Open DMG file
3. Drag EchoTune to Applications folder
4. Right-click → Open (first time only)

### First Launch

When you first open EchoTune:

1. **Welcome Screen**
   - Click "Get Started"

2. **Permissions Setup**
   - **Microphone Access**: Required to record your voice
     - Click "Grant Microphone Access"
     - Click "OK" in system dialog

   - **Accessibility Access**: Required to type in other apps
     - Click "Open System Settings"
     - Find EchoTune in list
     - Toggle switch ON
     - **Important**: Restart EchoTune after granting

3. **Free Trial**
   - 7-day free trial starts automatically
   - Full access to all features
   - No credit card required

## 🎙️ Basic Usage

### Recording Your Voice

**Method 1: Keyboard Shortcut (Recommended)**
```
Press: ⌘⇧D (Command + Shift + D)
Speak naturally
Press: ⌘⇧D again to stop
```

**Method 2: Menu Bar**
```
Click EchoTune icon in menu bar
Click "Start Recording"
Speak
Click "Stop Recording"
```

**Method 3: Dashboard**
```
Open EchoTune app
Click microphone button
Speak
Click stop button
```

### Where Text Appears

Text appears **automatically** wherever your cursor is:

- ✅ Chat apps (Slack, Messages, Discord)
- ✅ Documents (Pages, Word, Google Docs)
- ✅ Any text field on your Mac

**No copying or pasting needed!**

- English, Spanish, French, German, Italian
- Portuguese, Dutch, Russian, Polish, Turkish
- Arabic, Hindi, Urdu, Bengali, Punjabi
- Chinese, Japanese, Korean, Vietnamese
- And many more!

**To change language:**
1. Open Settings → AI Models
2. Select "Language"
3. Choose your language
4. Done!

### 4. Real-Time Visualization

Beautiful audio waveform shows you're recording:
- Green waves = recording active
- Red stop button = click to stop
- Visual feedback ensures you're being heard

### 5. Session History

View all your past transcriptions:
- See date and time
- Word count

- AI model used
- Playback (if audio was saved)

### 6. Statistics Tracking

Monitor your productivity:
- Total words transcribed
- Total sessions
- Time saved vs typing

## 🤖 AI Models

### Choosing the Right Model

**For Privacy:**
- Use **local models** (Whisper)
- Everything stays on your Mac
- Works offline
- No internet required

**For Speed:**
- Use **cloud models** (Groq)
- Ultra-fast transcription
- Requires internet
- You provide API key

**For Accuracy:**
- Use **larger local models** (Whisper Medium)
- Or **Deepgram Nova** (cloud)
- Slower but more accurate
- Better with accents and technical terms

### Downloading Local Models

1. Settings → AI Models → Local
2. Click "Download" next to model you want
3. Wait for download to complete (50MB - 1.5GB)
4. Select as default model
5. Done!

**Storage Requirements:**
- Tiny: ~50MB
- Base: ~150MB
- Small: ~500MB
- Medium: ~1.5GB

## 💡 Tips & Tricks

### For Best Accuracy

1. **Use a Good Microphone**
   - Built-in Mac mic works well
   - External mic is even better
   - USB headset recommended for noisy environments

2. **Speak Clearly**
   - Normal speaking pace
   - Don't rush
   - Enunciate clearly

3. **Reduce Background Noise**
   - Close windows
   - Turn off fans
   - Find quiet space

4. **Punctuation**
   - Say "period" or "full stop"
   - Say "comma" for pauses
   - Say "question mark" at end of questions
   - Or enable auto-punctuation in settings

### Pro Tips

**Tip 1: Use for Coding**
```
"function calculate total opening parenthesis items closing parenthesis
opening brace return items dot reduce opening parenthesis..."
```
Enable "Code Mode" in settings for better programming support.

**Tip 2: Multilingual**
- Select language before recording
- Or say "switch to Spanish" mid-recording
- Model auto-detects in some cases

**Tip 3: Templates**
- Create common phrases
- Save as templates
- Insert with shortcut

**Tip 4: Keyboard Shortcuts**
- Keep hands on keyboard
- `⌘⇧D` becomes muscle memory
- Much faster than clicking

**Tip 5: Batch Recording**
- Record multiple paragraphs
- Press ⌘⇧D once to start
- Keep talking
- Press again when completely done

## 🐛 Troubleshooting

### Recording Not Working

**Check:**
1. Microphone permission granted?
   - Settings → Privacy & Security → Microphone
   - EchoTune should be ON

2. Correct microphone selected?
   - EchoTune Settings → General → Input Device
   - Choose correct mic

3. Microphone working in other apps?
   - Test in Voice Memos
   - Check volume levels

4. Try different AI model
   - Some models may fail
   - Switch to another model

### Text Not Appearing

**Check:**
1. Accessibility permission granted?
   - System Settings → Privacy & Security → Accessibility
   - EchoTune should be ON
   - **Restart EchoTune after enabling**

2. Cursor in text field?
   - Click in text field first
   - Then start recording

3. App accepts typed input?
   - Some apps block programmatic typing
   - Try different app

### Poor Accuracy

**Try:**
1. Speak more clearly
2. Reduce background noise
3. Use larger AI model (Medium vs Tiny)
4. Try cloud model (Groq or Deepgram)
5. Ensure good microphone input levels
6. Select correct language

### Slow Transcription

**Solutions:**
1. Use smaller local model (Tiny vs Medium)
2. Switch to cloud model (Groq = fastest)
3. Close other apps
4. Restart Mac
5. Check available RAM

### Cloud Models Not Working

**Check:**
1. API key entered correctly?
2. API key has credits/quota?
3. Internet connection active?
4. Check provider status page:
   - status.groq.com
   - status.deepgram.com

### Trial Expired

2. Complete purchase ($39.99)
3. Instant unlock

**Direct Purchase:**
1. Visit echotune.app/purchase
2. Purchase license key
